CORE ARCHITECTURAL PILLARS

Institutional-Grade Reliability

Append-Only Double-Entry Ledger

Every rupee and paise is accounted for using immutable debit/credit postings. Database-level constraints reject any unbalanced transaction. Balance updates use atomic SQL increments to prevent race conditions.

Indian GST Statutory Engine

Calculates CGST + SGST (intra-state) vs. IGST (inter-state) with full statutory HSN categorization for solar photovoltaic cells (8541 @ 12%) and transformers/inverters (8504 @ 18%) with Mod-36 checksums.

Dual-Layer Idempotency Barrier

Fast-path Redis atomic reservation backed by persistent PostgreSQL hash constraints ensures network retry storms and payment gateway duplicates never result in double payouts or state desynchronization.

Transactional Outbox Webhooks

Outbound events are written atomically within the same DB transaction as escrow state changes. An asynchronous worker with exponential backoff guarantees at-least-once delivery with HMAC-SHA256 signatures.

Automated Nightly Reconciliation

Continuous audit engine cross-checks bank gateway clearing ledger balances against escrow liability totals to pinpoint and alert on any account drift, maintaining zero drift across multi-million transactions.

Comprehensive Test Rig & CI

100-worker concurrency release stress test, Hypothesis property-based testing of double-entry invariants, Ruff linting, Mypy typing, and 88.5% test coverage validated on every pull request via GitHub Actions.

Ready for Production Integration

All endpoints are documented with OpenAPI 3.1.0 and interactive Swagger UI. Authenticate via Bearer JWT with granular role-based access control (BUYER, SELLER, LOGISTICS, ADMIN).
